# 🖤 THE OTHER SIDE (디 아더 사이드)
> **“AI가 영웅의 빛 뒤에 가려진 빌런의 서사를 하나의 기밀 사건철로 감정한다.”**

---

## 1. 서비스 명
* **서비스 국/영문 명칭**: THE OTHER SIDE (디 아더 사이드)
* **초기 프로토타입 명칭**: 빌런 서사 아카이브 (Villain Dossier Engine)
* **슬로건**: “AI가 당신이 주목한 빌런의 결핍과 신념을 하나의 기밀 프로파일링 사건철로 편철한다.”

---

## 2. 서비스 정의
* **정의**: 사용자가 주목하는 빌런, 안티히어로, 다크 히어로 인물과 작품 키워드를 입력하면, AI가 단순 악행 나열을 넘어 **“범죄 심리 프로파일링 기반의 구조화된 기밀 문서(Dossier)”**로 재구성해주는 AI 서사 아카이빙 플랫폼
* **핵심 지향점**: 단순 메모나 캐릭터 소개를 넘어 **“악의 결핍과 트라우마를 서사화하고 영구 소장 가능한 형태로 큐레이션해주는 콘텐츠 엔진”**

---

## 3. 기획 배경 (문제 인식)
* **단편적인 악역 소비**: 매력적인 안티히어로의 입체적 서사(결핍, 배신, 명분)가 인터넷 커뮤니티나 클립 영상 등에 파편화되어 체계적인 아카이빙이 불가능함
* **빌런 매력 설명의 한계**: "왜 이 악역에게 매혹되는가"를 타인에게 설명할 때 심리적이고 서사적인 논리 구조가 부족함
* 🔥 **핵심 문제**: *“매혹적인 빌런은 너무 많은데, 그 악의 이면을 구조화하여 입체적으로 조명할 전문 프로파일링 도구가 없는 상태”*

---

## 4. 서비스 발전 과정 (초기 MVP ➔ 최종 Noir Editorial 버전)
실제 사용자 피드백과 콘텐츠 확장성을 고려하여 2단계 이터레이션(Iteration)을 거쳐 프로덕트를 고도화했습니다.

```plaintext
[Phase 1. 초기 MVP : 빌런 아카이브] ────► [Phase 2. 최종 확장 : THE OTHER SIDE]
· 타깃: 특정 대중 영화 악역 한정           · 타깃: 영화, 문학, 애니메이션 등 서브컬처 빌런 전반
· 톤앤매너: 단순 다크 UI                     · 톤앤매너: 하드보일드 누아르 & 기밀 수사철
· 산출물: 단순 텍스트 요약                   · 산출물: '5단 심리 서사 감정서' (전문 프로파일러 문체)
· 4개 탭: 분석 / 추천 / 보관 / 링크          · 5개 탭: PROFILER / DOSSIER / ESSAY / MOODBOARD / ARCHIVE BOOK
```

* **초기 프로토타입 단계 (Phase 1 - MVP)**:
  * **핵심 기능**: 악역 이름과 키워드를 넣으면 결핍과 명분을 요약하고 보관함에 저장하는 구조 검증
  * **한계점 발견**: 텍스트 서식이 밋밋하고 마크다운 문법이 깨져 하드보일드한 몰입감을 주기에 제약이 있음
* **최종 고도화 단계 (Phase 2 - Noir Editorial System)**:
  * **기밀 수사철 룩앤필 도입**: 핏빛 네온 레드와 차콜 블랙 기반의 정통 누아르 수사 문서 인터페이스 구축
  * **기능 확장**: 심리 감정(PROFILER), 기밀 선집 퀵필(DOSSIER), 비평 지면(ESSAY), 미학 보드(MOODBOARD), 사건철 서가(ARCHIVE BOOK) 등 5개 탭 SPA 구조로 전면 리브랜딩

---

## 5. 해결 전략 (3단 구조화)
* **5.1 AI 심리 분석 엔진**: 대상의 핵심 표상, 결핍의 기원, 방어기제 및 정당화 논리, 대척점(영웅)과의 거울상 관계, 관련 현장 기록(유튜브)을 자동 결합 추출
* **5.2 기밀 문서 지면 구조화**: `[CLASSIFIED DOSSIER]` 헤드라인 ➔ 5단 심층 감정 ➔ 유튜브 증거물 링크 ➔ 프로파일러 판정으로 이어지는 클래식 수사 포맷 제공
* **5.3 영구 아카이빙 시스템**: 생성된 고품질 프로파일링 리포트를 유실 없이 브라우저 로컬 저장소에 사건 번호(`CASE #`)별로 영구 편철 및 관리

---

## 6. 주요 기능 상세 명세
* **6.1 Dossier 서사 감정 (PROFILER)**: 인물명, 작품명, 단서 메모 입력 시 비동기 AI 심리 프로파일링 보고서 즉시 생성
* **6.2 5탭 SPA UI 시스템**: 01. PROFILER / 02. TOP 4 DOSSIER / 03. ESSAY & THEORY / 04. MOODBOARD / 05. ARCHIVE BOOK의 직관적 탭 네비게이션
* **6.3 큐레이션 & 유튜브 연동**: 조커, 스네이프, 말레피센트, 한니발 렉터 원클릭 퀵필(QuickFill) 및 유튜브 현장 기록 영상 바로가기 링크 자동 인코딩 연결
* **6.4 테마 및 반응형 시스템**: 다크(하드보일드 누아르) / 라이트(기밀 수사문서 질감) 모드 실시간 토글, 🖤 커스텀 파비콘, 모바일 가로 스크롤 최적화
* **6.5 실패 및 예외 처리 UX**:
  * **빈 입력(Validation)**: 필수 인물명 누락 시 알림창을 띄우고 API 호출 차단
  * **지연 처리**: 프로파일링 대기 시 기밀 데이터베이스 대조 스피너 로딩 제공
  * **API 에러**: 통신 에러 발생 시 사용자 안내 메시지 노출

## 7. 타겟 사용자 및 니즈 분석
* **주 타깃**: 영화/드라마 마니아, 서브컬처 캐릭터 애호가, 서사 창작자(작가/지망생)
* **부 타깃**: 심리학 및 범죄 프로파일링 담론, 문화 비평을 즐기는 2030 세대

  * 타인에게 설득력 있는 '빌런 서사 리포트'를 공유하고 소장하고 싶은 욕구

## 9. 기술 아키텍처 및 디렉터리 구조

### 9.1 시스템 기술 스택
* **Frontend**: HTML5, CSS3 (Noir Dark & Paper Light), Vanilla JavaScript (SPA, `marked.js`)
* **Backend**: Vercel Serverless Functions (`api/chat.py`, `Python 3.9+`)
* **AI Engine**: Google Gemini API (`gemini-3.5-flash`)
* **Deployment & CI/CD**: GitHub, Vercel
* **Security & Ops**: `GEMINI_API_KEY` 환경 변수 분리

### 9.2 디렉터리 구조 (Directory Tree)
```plaintext
The-Other-Side/
├── api/
│   ├── chat.py             # Serverless POST 엔드포인트 (Gemini AI 연동)
│   └── prompts.py          # 범죄 프로파일러 페르소나 및 정형 출력 프롬프트

│   ├── css/
│   │   └── style.css       # 누아르/라이트 테마 통합 메인 스타일시트
│   ├── js/
│   │   └── app.js          # SPA 라우팅, 마크다운/링크 파싱, LocalStorage 편철
│   └── index.html          # 단일 페이지 애플리케이션(SPA) 메인 마크업

```

## 10. UX 및 데이터 처리 흐름

```plaintext
1. [사용자 입력] ─────> 2. [app.js Validation] ─────> 3. [fetch('/api/chat', POST)]
                                                               │
                                                               ▼
6. [사건철 렌더링/편철] <── 5. [Markdown 파싱/DOM] <── 4. [chat.py + Gemini AI]
```

* **1~2단계**: 사용자가 대상 빌런과 단서를 입력하면 브라우저(`app.js`)에서 유효성 검증 후 비동기 호출을 시작합니다.
* **3~4단계**: `fetch('/api/chat')`를 통해 백엔드 서버리스 함수로 데이터가 전달되며, 프로파일러 프롬프트와 결합되어 Gemini AI 엔진을 호출합니다.
* **5~6단계**: AI가 반환한 감정서 텍스트를 수신하여 마크다운 및 유튜브 링크를 정규식으로 파싱한 뒤, 누아르 수사철 지면으로 화면에 렌더링하고 `ARCHIVE BOOK`에 영구 편철합니다.

## 11. 향후 확장 계획 (Roadmap)
* **11.1 공유형 기밀 링크 (Dossier Web Link)**: 생성된 사건철별 고유 케이스 번호 링크(URL) 및 SNS 공유 카드 발급
* **11.2 PDF 수사 보고서 내보내기 (Printable Classified File)**: 사건철을 실제 수사기관 감정서 양식의 A4 PDF로 내보내는 다운로드 기능 지원
* **11.3 다크 아카이브 커뮤니티 (Collective Dossier)**: 사용자들이 분석한 빌런 사건철을 서로 열람하고 비교 분석할 수 있는 공개 서가 피드 구축
